ESP32-C3 Zero

Firmware Flasher

Installiere deine Test-Firmware direkt über den Browser auf einem ESP32-C3 Zero.

Benötigte Hardware

Benötigt wird ein ESP32-C3 Zero und ein USB-Datenkabel. Partitionstabelle, Bootloader und Firmware werden direkt über Web Serial installiert.

ESP32-C3 RISC-V Wi-Fi Bluetooth LE USB-C

Vorbereitung

  • ESP32-C3 Zero über ein USB-Datenkabel verbinden.
  • Google Chrome oder Microsoft Edge auf einem Desktop-PC verwenden.
  • Bei Problemen die BOOT-Taste gedrückt halten und RESET kurz drücken.
  • Im folgenden Dialog den passenden seriellen Port auswählen.
Bereit für die Installation

Nach dem Klick wird der serielle Port ausgewählt. Anschließend werden Partitionen und Firmware automatisch geflasht.
