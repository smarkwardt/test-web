Benötigtes Display

Benötigt wird ein Waveshare ESP32-S3-Touch-AMOLED-1.64. Das 1,64 Zoll AMOLED-Touchdisplay dient als kompaktes SUPER VOLT Display und kommuniziert per Bluetooth.

1,64 Zoll AMOLED ESP32-S3 Touchscreen Bluetooth

Vorbereitung

  • Display über ein USB-Datenkabel mit dem Computer verbinden.
  • Prüfen, ob das Gerät als COM-Port bzw. serielles Gerät erkannt wird.
  • Falls nötig den USB-Seriell-Treiber installieren.
  • Einen Desktop-PC mit aktuellem Google Chrome oder Microsoft Edge verwenden.
Bereit für die Installation

Nach dem Klick wird der serielle Port ausgewählt. Anschließend startet die Installation automatisch.
